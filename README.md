# Z v5.0 — Gemini Android Assistant

Барномаи Android бо интерфейси чатӣ. Барои суҳбат дигар фармонҳои Termux лозим нестанд.

## Хусусиятҳо
- Чати матнӣ бо Gemini API
- Интерфейси тоҷикӣ ва Dark UI
- Нигоҳ доштани таърихи суҳбат дар телефон
- Ворид ва иваз кардани API Key дар дохили барнома
- GitHub Actions барои сохтани APK
- Package: `tj.soni.z`
- Min Android: 8.0 (API 26)

## Сохтани APK аз GitHub
1. ZIP-ро кушоед ва ҳамаи файлҳоро ба repository-и GitHub бор кунед.
2. Номи branch-и асосӣ `main` бошад.
3. Ба Actions гузаред.
4. Workflow-и **Build Z APK**-ро кушоед ва **Run workflow**-ро пахш кунед (ё баъди push худкор оғоз мешавад).
5. Пас аз анҷоми сабз, аз қисми Artifacts файли `Z-v5.0-apk`-ро зеркашӣ кунед.
6. ZIP-и artifact-ро кушоед ва `app-debug.apk`-ро насб кунед.

## Пайваст кардани Gemini
1. Дар Google AI Studio калиди API созед: https://aistudio.google.com/
2. Z-ро кушоед.
3. Нишонаи ⚙ Танзимотро пахш кунед.
4. API Key-ро ворид карда, **Сабт кардан**-ро пахш кунед.
5. Саволро дар чат нависед ва Ирсол кунед.

Модели пешфарз: `gemini-3.8-flash`.

## Муҳим дар бораи амният
- API Key-ро ба GitHub, ZIP-и оммавӣ ё чат нафиристед.
- Калид дар SharedPreferences-и хусусии барнома нигоҳ дошта мешавад. Ин нигоҳдорӣ барои истифодаи шахсӣ қулай аст, аммо муҳофизати комил аз истихроҷи калид аз APK/дастгоҳ нест.
- Барои барномаи оммавӣ proxy/backend-и худатон лозим аст; калиди шахсиро дар APK ҷой надиҳед.
- Маҳдудиятҳо ва нархи Gemini API аз ҳисоби Google ва модели интихобшуда вобастаанд.
